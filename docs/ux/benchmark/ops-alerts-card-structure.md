## 채택안 — B + C

**B. 제목·설명 두 줄 → 12px 메타 한 줄** (`설치 필요 3건 · 인프라 담당`)

- 조각은 **이름 · 건수 · 담당** 셋, 상한도 셋. 넷을 넘으면 다시 문단이 된다.
- 건수는 타일에도 남는다 — **의도한 중복**(레퍼런스 01·13). 지운 것은 중복이 아니라 제목 계층이다.
- 담당은 버킷별 `owner` 필드. 연결 테스트 버킷은 원래 문구가 행위자를 부르지 않아 `null` 이고,
  그 조각과 구분점이 함께 빠진다. 화면이 admin 전용이라는 이유로 "관리자"를 채우면 네 버킷이
  전부 관리자가 되어 조각이 아무것도 가르지 못한다.
- "지연 오래된 순" 같은 정렬 조각은 **넣지 않았다**: upstream 이 정렬을 보장하지 않고,
  실제 응답도 지연 순이 아니다(1861 3일 → 1520 8시간 → 1388 1일).

**C. 카드 제거** — 테두리·그림자를 걷고 표가 페이지 바닥에 선다. 셀 패딩 px-5 만큼 `-mx-5` 로
블록을 당겨(대시보드 `listBlock` 과 같은 값) 첫 열 값이 h1·타일과 같은 x 에 선다.

### 아티팩트 권고에서 벗어난 것 하나

아티팩트는 "메타 줄 ↔ 표 간격 12px → 24px"을 적었는데, **12px 을 유지했다**.
그 24px 은 카드 패딩 20px 과 비교해서 나온 값이고, C 로 카드가 사라지면서 비교 대상이 바뀐다.
지금 비교는 `타일 → 메타`(24px) 대 `메타 → 표`(12px) 이고, 메타는 그 표의 설명이므로
가까운 쪽이 자기 표여야 한다(여백 7원칙 #2 비대칭 그룹핑). 2:1 로 "섹션 간 ≥ 내부의 2배"도 만족한다.

### 기각

| 시안 | 기각 사유 |
|---|---|
| A — 머리 통째로 삭제 | B 의 축소판. P6(건수)이 남고, 스크롤로 타일이 나가면 단서가 URL 뿐 |
| D — 머리 자리에 검색·정렬 툴바 | 검색·정렬이 계약에 없다(`kind`/`page`/`size` 뿐). 지금 2~3건 규모엔 도구가 데이터보다 크다. 버킷이 100건대가 되면 재검토 |
| E — 담당을 열로 | 버킷당 담당이 하나라 열 값이 10행 내내 같다. 같은 값만 반복하는 열은 정보가 아니다. 버킷마다 담당이 갈릴 때만 성립 |
