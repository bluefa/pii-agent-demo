## 1. 왜 했나

"계층이 안 잡혀서 그런가? 페이지가 너무 힘이 없어 보인다.
강약이 있어야 되는데 강이 전혀 없다."

앞선 세 라운드가 행·레일·밀도를 각각 고쳤는데도 같은 지적이 반복됐다.
요소를 하나씩 고쳐서 안 풀린다면 문제가 요소에 없다는 뜻이라, 이번엔 화면 전체를 쟀다.

## 2. 진단 (실측 · 1920×902 Chrome)

| # | 문제 | 측정값 · 대조 | 등급 |

| 2 | 페이지 제목이 최소 | 우리 `30px`. 실측 10곳 중앙값 `48`, 최소 32(Stripe) 최대 54(네이버웍스) | 수치 |
| 3 | 큰 글자가 한 번만 나온다 | `30px` 는 페이지에 1회. 목록에서 반복되는 최대 활자는 `18px`.<br>Linear `32×10` · Stripe `20×123` · 토스페이먼츠 `20×25` | UX 원칙 |

| 5 | 행은 큰데 담긴 게 적다 | 우리 행 `94px` 에 18px 한 줄. NHN `72px` 4열 · NCP `45px` 3요소 | 수치 |

**핵심**: 강약은 큰 글자를 하나 놓아서 생기지 않고 덮는 것과 안 덮는 것의 차이로 생긴다.
덮는 쪽이 없으면 대비할 상대가 없다. 진단 2·3·4가 전부 그 한 가지를 다른 각도로 말한다.

## 4. 채택 — C → B → A

순서가 결론의 일부다. **빈 화면에서 밴드부터 올리면 "위는 큰데 아래는 여전히 빈" 상태**가 된다.

### 시안 C — 제목을 한 칸 올리고 행을 조인다 (`29214c2a`)

- `entryTitle` `18 → 22px` — 잰 13곳 중 목록 제목이 18px 인 곳이 없었다
- `groupTitle` `14 → 16px` — 머리가 머리 노릇을 하려면 아래 내용보다 커야 한다
- `entryRow` 세로 여백 `18 → 14`, `entryMain` 간격 `8 → 6` → 행 `94/66 → 90/60px`
- `entryDate` `pt-[5px] → pt-[7px]` — 배지 있는 행과 없는 행 양쪽에서 윗선을 맞춘다
- 결과: 잉크 `5.4% → 6.4%`

### 시안 B — 첫 글은 펼친 채로 시작 (`3c8cf9c6`)

- 보이는 목록의 첫 글에 `defaultOpen` 을 준다. 계약이 목록에 요약을 안 주니
  (tag guide §5) **요약을 새로 만드는 대신 이미 있는 본문을 한 건 편다**
- 본문 요청을 클릭 핸들러에서 **펼침 상태**로 옮겼다 — 처음부터 펼친 행은
  누른 적이 없어서 `toggle` 안에 두면 본문이 영영 안 온다
- 목록 컨테이너에 `key={category}` — 없으면 `전체` 에서 접힌 채 마운트된 행이
  자기 Category 로 가도 접혀 있어 규칙이 깨진다
- 비용: 진입 시 `GET /posts/{id}` 1회

### 시안 A — 제목 밴드 (`3c8cf9c6`)

- `pageBand` 전폭 밴드, `bandTitle` `40px`
- 면 색은 **레일과 같은 `#EEF1F7`** — 이 화면의 규칙이 "회색은 구조, 흰색은 내용"
  하나라 밴드에 새 회색을 들이면 규칙이 둘이 된다
- `pageTitle`(30px) 은 그대로 둔다 — Admin 두 화면이 같은 토큰을 쓴다
- 세로 비용은 보이는 것보다 작다. 기존 레이아웃이 이미 `pt-8` + 제목 블록 56 +
  `gap-6` 을 쓰고 있었어서 밴드가 그 자리를 대체한다. 실측 밴드 `132px`,
  목록 칸 `749 → 656px` — 순 비용 `93px`
- `pageBody` 의 `min-h-0` 은 뮤테이션으로 확인했다. 떼고 94행을 넣으면 목록 칸이
  `656 → 7416px` 로 부풀고 `pageFill` 이 잘라 6760px 가 닿지 않는다.
  `catNav`·`listPane` 과 달리 이 칸은 스크롤 컨테이너가 아니라 자동 최소 크기가 0 이 아니다

**결과**: 잉크 `5.4% → 12.2%`

## 5. 채택하지 않은 것

- **시안 D(종류를 색으로)** — NHN 3색 배지 · GitHub 3색 아이콘을 따르려면 종류 축이 필요한데
  계약에 없다. `categoryName` 은 Admin 자유 입력 문자열이라 이름이 바뀌면 색이 회색으로 떨어진다.
  **계약에 종류 축이 생기면 그때** 한다.
- **시안 E(읽기 폭 중앙 정렬)** — 13곳 중 전폭을 쓰는 곳이 없어 근거는 가장 확실하지만,
  **좌우 마진을 63 → 24px 로 줄인 직전 결정과 정면으로 반대**다. 되돌리려면 별도 결정이 필요하다.

## 6. 답하지 않은 것

- **NOTICE 글이 2건이다.** C·B 는 건수와 무관하게 듣지만 진단 6(화면당 2행)은
  콘텐츠가 쌓여야 풀린다.
- **`yy-mm-dd` 날짜 포맷**은 여전히 스펙(tag guide `publishedAt`)이 고정한 값이다.
  13곳 전부 사람 포맷을 쓰지만 디자인 결정이 아니다.
