# Design Guide — 오너 제공 가이드 3종의 요약 권위

출처(2026-07-05 오너 제공): ① 모바일 UI 여백 7원칙 ② 웹 레이아웃·그리드 수치 시스템
③ UI 폰트·여백·시스템 가이드. 핵심 명제는 셋 다 같다:
**"디자인은 감각이 아니라 시스템이다 — 모든 값에는 세트와 근거가 있다."**

적용 우선순위: 프로젝트별 SSOT가 있으면 그쪽이 우선
(admin-pipeline은 `design/pipeline/admin-pipeline-style-guide.md`). 이 skill은
새 화면·새 프로젝트에서 값을 정할 때의 기본값이자, SSOT에 없는 상황의 판단 기준.

## 1. 수치는 세트에서만 (가이드 ②·③)

| 항목 | 세트 |
|---|---|
| 폰트 크기 | **12/14/16/18/20/24/28/32/36/40/48**만. 본문 14(~16), 최소 12, 타이틀 18~24. 중간값(13, 12.5…) 금지 |
| 행간 | 2단만 — **120%**(제목·라벨·숫자 등 한 줄 성격) / **140%**(읽는 글) |
| 간격 | 8의 배수 골격(미세 간격 4 허용): 4/8/12/16/24/32/40… 큰 네거티브 스페이스는 페이지 성격당 상수 1개(밀도형 어드민 40, 마케팅형 80~120) |
| 좌우 마진 | 16/20/24 중 하나 |
| 카드 패딩 | 상 20 · 좌우 24 · 하 24 |
| 컨트롤 높이 | 버튼=셀렉트=인풋 **동일 높이**. 터치 52/48/40/36, 데스크톱 밀도형은 32/28 계열 허용 |
| 명도 대비 | 텍스트:배경 **4.5:1 이상** |

- 새 값이 필요해 보이면 세트에 값을 추가하지 말고 **역할 배정을 재검토**한다.
- **케이스 축소가 실력**: 크기·무게·간격의 가짓수가 적을수록 시스템이 된다.

## 2. 여백 7원칙 — 여백은 빈 공간이 아니라 기능이다 (가이드 ①)

1. **넓게 시작해 좁혀라** — 좁게 시작하면 조금씩밖에 못 넓힌다. 과감히 띄운 뒤 조인다.
2. **비대칭 그룹핑** — 제목↔내용은 붙이고, 그룹이 끝나는 하단은 더 넓게. 상하 여백이
   같으면 콘텐츠가 붕 뜬다. (제목의 위 여백 > 아래 여백, 그룹 하단 > 그룹 상단)
3. **클릭·터치 영역 먼저** — 텍스트가 버튼이면 보이지 않는 버튼 영역부터 설계.
   물리적 여백이 오클릭을 막는다.
4. **카드 디테일** — 내부 여백 충분히. 라운드가 클수록 콘텐츠를 안쪽으로 들여 써야
   그룹핑이 완성된다. 라운드는 인상(부드러움)의 도구다.
5. **스캔 속도 기준** — 사용자는 멈춰서 보지 않고 스치듯 스크롤한다. 단(행·카드) 사이
   여백은 "이 정보가 어느 항목 소속인지" 찰나에 읽히는 수준으로.
6. **카드 UI vs 바닥 UI** — 경계선 없는(바닥) 레이아웃은 여백만으로 위계를 만들어야
   해서 난이도가 높다. 확신이 없으면 카드로 감싸라.
7. **여백 = 시선 유도** — 사용자는 타이틀을 본 뒤 본문을 건너뛰고 액션을 찾는다.
   핵심 요소 주변에 여백을 몰아주고, 덜 중요한 것은 뭉쳐도 된다.

## 3. 정보 계층 만들기 (가이드 ①§7 + ③)

- **역할 수를 먼저 세고, 역할당 크기 1개** — 크기 가짓수는 역할 수와 같다.
- **인접 계층은 레버 2개 이상 차이**(크기·무게·색) — 1px 차이는 계층이 아니라 오차.
- **거리 자체가 정보 구조**: 층위가 다르면 거리도 달라야 한다. 섹션 간 여백은
  섹션 내부 여백의 2배 이상.
- 뭉탱이 금지: 여백이 균일하면 모든 정보가 한 덩어리로 읽힌다.

## 4. 작업 규칙

- **레퍼런스는 실물로**: 시안 비교·벤치마킹은 탑 프로덕트(Linear, Vercel, 네이버 등)의
  실측 데이터로 한다. 감으로 그린 시안끼리 비교하지 않는다. (가이드 ③의 트레이싱 원칙)
- **값 결정은 프로세스 안에서**: `design/pipeline/design-process.md`의 현재 단계를 먼저
  확인 — 수치·계층 결정이 어느 단계 소관인지 선언하고 작업한다.
- 그리드: 데스크톱 캔버스 기준 폭 1280 · 12컬럼을 기본 좌표계로 삼는다
  (admin content `max-width:1280px`와 합치).
