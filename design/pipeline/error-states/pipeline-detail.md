## 상세

### 3. 폴링 실패 — P4

- 연속 2회 실패 시 헤더 우측에 `업데이트 지연 — 마지막 갱신 19:41` (text-weak, 아이콘 ◌)
- 성공 tick이 오면 즉시 소멸. 실패마다 알림을 쌓지 않는다 — 지속 상태는 지속 표면에.
- 진행바·상태 배지는 마지막 스냅샷 유지 (지금과 동일)

### 4. 드로어 재시도 — 실패도 버튼이 말하게

현재 `retrySelectedDetail`은 실패해도 침묵. 재시도 버튼에 P3 적용:

```
[재시도] → 클릭 → [◌ 불러오는 중] → 실패 → [실패 — 다시 시도] (1.5s 후 라벨 원복)
```

### 5. JobViewer — 상태 구분 유지 + 재시도 신설

- `notfound`(로그 기록 없음)와 `error`(로드 실패)의 문구 구분은 현재가 잘 되어 있음 — 유지
- `error`에만 재시도 버튼 추가 (뷰어를 닫았다 여는 우회 제거)
- 404는 데이터 특성이므로 재시도 버튼 없음

### 6·7. 취소 — 모달 안에서 끝내고, 결과는 배지로

- 실패: P2 알럿(원인 + "잠시 후 다시 시도"), 취소 버튼은 loading → 원복. 모달 유지.
- 성공: 모달 닫힘 → 헤더·캔버스 배지가 즉시 `CANCEL_REQUESTED`(또는 `CANCELLED`)로 전이(P5). 다음 폴링이 확정. 배지가 확인이므로 토스트 불필요.

### 8. 복사 버튼 — P3

```
[⧉ 복사] → 클릭 → [✓ 복사됨] → 포인터 이탈 시 원복
                    └ 실패 시 [✕ 복사 실패] → 동일하게 원복
```
