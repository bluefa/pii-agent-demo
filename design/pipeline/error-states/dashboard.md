## 상세

### 1. KPI 타일 — 타일 단위 에러 상태

타일이 자기 상태를 스스로 표현한다. 페이지 전체를 막지 않는다.

```
[정상]   실행 중          [에러]   실행 중
         12                        ⚠ 확인 실패
                                   (타일 클릭 = 재시도)
```

- 값 자리: `⚠ 확인 실패` (12px, text-weak — 화면을 붉게 물들이지 않음, 아이콘만 warn 톤)
- 타일 전체가 재시도 버튼 역할 (hover 시 커서·배경 전이 + title="다시 불러오기")
- 재시도 중엔 값 자리 스켈레톤 → 성공 시 숫자로, 실패 시 다시 ⚠로 전이
- 로딩(첫 진입)은 스켈레톤 — `—` 를 로딩 표시로 쓰지 않는다 (실패와 구분 불가하므로)
- "실패" 타일의 빨간 강조는 지금처럼 `failedCount > 0` 의미로만 사용, fetch 실패와 혼동 금지

### 2. 목록 영역 — P1 에러 상태 카드

- 테이블 자리 전체를 P1로 대체: 아이콘 + "파이프라인 목록을 불러오지 못했습니다" + 서버 메시지(보조, mono 축약) + `재시도`
- raw `err.message`를 제목으로 쓰지 않는다 — 제목은 고정 문구, 서버 메시지는 보조 라인
- 필터·기간 컨트롤은 살아 있음 (조건 변경도 재시도 경로)

### 3. 빈 상태

현재 분기 유지. 에러(#2)와 시각적으로 구분: 빈 상태는 회색 톤·재시도 없음, 에러는 warn 아이콘·재시도 있음.
