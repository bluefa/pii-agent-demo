## 상세

### 1. 미리보기 실패 — 나가지 않고 회복

- Task 목록 자리에 에러 상태: warn 아이콘 + "미리보기를 불러오지 못했습니다" + 서버 메시지 보조 + `재시도`
- 실행 버튼은 미리보기 성공 전까지 disabled (현재 로직 유지)

### 3. 실행 실패 — 버튼과 알럿이 함께 전이

```
[▶ 설치 시작] → 클릭 → [◌ 실행 요청 중] (버튼 disabled)
   ├ 성공 → 모달 닫힘 + 이동 (#6)
   └ 실패 → 버튼 원복 + 푸터 위에 P2 알럿 등장:
            (!) 파이프라인 실행에 실패했습니다
                {서버 메시지 요약} — 잠시 후 다시 시도하세요
```

- 알럿은 다음 실행 시도 시작 시점에 제거 (상태 전이로 소멸)
- 버튼 라벨을 "실패"로 바꾸지 않는다 — 원인 설명이 필요한 실패는 알럿이 담당, 버튼은 재시도 수단으로 원복

### 4. 409 — 사용자가 결정하는 이동

```
(!) 이미 진행 중인 파이프라인이 있습니다
    한 대상에는 동시에 하나의 파이프라인만 실행됩니다.
    [현재 실행으로 이동 →]
```

- 말없는 자동 이동 제거 — 사용자가 입력한 Custom 구성이 통째로 날아가는 부작용도 함께 제거됨
- "현재 실행으로 이동" 클릭 시에만 라우팅. 최신 실행 조회는 이 클릭 시점에 수행하고, 실패하면 같은 알럿 안에서 "확인 실패 — 다시 시도" 상태로 전이 (#5가 모달 안으로 흡수되는 지점)

### 6. 실행 성공 — 도착 화면이 확인

- 모달 닫힘 → 상세 화면 이동 → 현재 파이프라인 카드에 새 실행이 RUNNING으로 표시
- 선택 강화: 카드 최초 진입 시 1회 하이라이트(배경 페이드)로 시선 유도 — 토스트 없이 "방금 시작됐다"를 전달
