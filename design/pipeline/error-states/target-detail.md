## 상세

### 2. 현재 파이프라인 카드 — 실패를 "없음"으로 위장하지 않기 (가장 중요)

조회 실패가 빈 카드로 보이면 사용자는 "실행이 없다"고 믿고 새 파이프라인을 시작할 수 있다.
서버에는 실행이 있으므로 409를 맞는다 — **오작동을 유도하는 위장**.

카드가 세 가지 상태를 구분해 전이한다:

| 카드 상태 | 표시 | 시작 CTA |
|-----------|------|----------|
| 실행 없음 (정상 빈 상태) | 기존 EmptyPipelineCard ("실행 중인 파이프라인이 없습니다" + 시작 CTA) | 노출 |
| 조회 실패 | warn 아이콘 + "현재 파이프라인을 확인하지 못했습니다" + 재시도 버튼 | **숨김** (확인 전 시작 금지) |
| 로딩 | 스켈레톤 | 숨김 |

### 3. 이력 섹션 — 에러 ≠ 빈

- 실패: 테이블 자리에 P1 컴팩트 — "이력을 불러오지 못했습니다" + 재시도. 페이지네이션 숨김.
- 빈: 기존 "파이프라인 이력이 없어요" 유지.
- 이력 실패는 페이지 전체를 막지 않는다 — 대상 정보·현재 파이프라인 카드는 독립적으로 렌더.

### 4. 폴링 실패 — P4

pipeline-detail과 동일 규격 (연속 2회 실패 시 "업데이트 지연 — 마지막 갱신 HH:MM", 회복 시 소멸).
