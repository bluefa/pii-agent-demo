# 서비스 대상 검색 — 에러 표현 명세

- 화면: `/integration/admin/pipelines/services` (`app/admin/pipelines/services/page.tsx`)
- 데이터: 서비스 목록(좌측 레일) + 대상 목록(우측) + 행별 최신 실행(LatestCell)
- 공통 원칙·패턴(P1~P5): [00-overview.md](./00-overview.md)

## 에러 상황별 표현

| # | 상황 | 현재 동작 | 개선 (상태 전이) | 재시도 | 토스트 |
|---|------|-----------|------------------|--------|--------|
| 1 | 서비스 목록 fetch 실패 | PlEmptyState(search 아이콘) + raw message + 재시도 | P1 (레일 폭에 맞는 컴팩트 변형) | 있음(유지) | 불필요 |
| 2 | 대상 목록 fetch 실패 | PlEmptyState(inbox 아이콘) + raw message + 재시도 | P1 | 있음(유지) | 불필요 |
| 3 | 행별 최신 실행 조회 실패 | 침묵 삼킴 → `—` (실패가 "실행 없음"처럼 보임) | 셀 단위 에러 상태 전이 | 셀에서 | 불필요 |
| 4 | 검색 결과 없음 / 대상 없음 | "검색 결과 없음" / "target source 없음" | 유지 (에러와 분기 분리 유지) | — | 불필요 |

## 상세

### 1·2. 목록 실패 — P1 정렬

- 구조(재시도 포함)는 이미 맞음. 시각만 정렬: 에러용 warn 아이콘(검색/inbox 아이콘 재사용 금지), 고정 제목 + 서버 메시지 보조 라인, `role="alert"`
- 좌측 레일은 폭이 좁으므로 P1 컴팩트 변형(아이콘 32px, 세로 스택)

### 3. LatestCell — 셀 단위 상태 전이

의미가 다른 세 가지를 시각적으로 분리한다:

| 셀 상태 | 표시 |
|---------|------|
| 로딩 | 스켈레톤 바 |
| 실행 이력 없음 (204/null) | `—` (지금과 동일, text-faint) |
| 조회 실패 | `⚠` 아이콘 + hover tooltip "최신 실행을 확인하지 못했습니다 — 클릭해서 재시도", 클릭 시 해당 셀만 재조회 (스피너 → 성공 시 값 / 실패 시 ⚠ 유지) |

행 전체·페이지를 막지 않는다. 셀 하나의 문제는 셀 안에서 끝낸다.
