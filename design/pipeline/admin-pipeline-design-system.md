## 0. 캐릭터 선언 (Phase 0 결정 — 모든 판단의 심판 기준)

**n8n 실행 화면(구조) + Linear(표면·밀도 감각)** — 정밀하고, 조용하고, 상태색이 주인공.

- 구조는 이미 IA v2에 반영됨(상주 상태 바 + 그래프 본문 + 사이드 패널).
- 표면 해석: 절제된 무채색 위에 **상태색만 유일하게 산다**. 액센트(primary)는 1색,
  링크·선택·포커스에만. 장식 금지.

### 1-3. 나란한 카드 정렬 규칙

**같은 행(grid row)에 서는 카드는 높이가 같아야 한다.**

- `.detail-grid` `.two-col` `.meta-2`: `align-items: stretch` + 행 공통 `min-height`
- sticky가 필요하면 stretch를 포기하는 게 아니라 **패널 내부 스크롤**로 해결
  (`.sidepanel > .card { height: 100% }`)
- 근거: 실측 — Task 흐름 카드 264px 옆에 사이드 패널 411px(#124), 233 vs 84(#128)

## 2. 표면 밝기 사다리 — Phase 3 variant로 확정

공통 원칙: 표면은 **page → card → inner 3단** + 다크 앵커 여부가 variant 축.

| Variant | 성격 | 사다리 |
|---|---|---|
| **A. 전면 다크** | Linear dark × n8n 실행. 상태색이 가장 강하게 삶 | page #0E1015 → card #16181E → inner #1C1F26, 텍스트 #F7F8F8→#5D6470 4단, primary #7C8AEF |
| **B. 다크 크롬 + 라이트 캔버스** | 탑네비·사이드바만 #101828, 콘텐츠는 현행 라이트. 변경 최소 | 크롬 #101828/#1D2939, 캔버스 현행 유지, FAILED 상태 바만 틴트 표면 |
| **C. 고대비 정밀 라이트** | Linear light. 밝음을 유지하되 텍스트 대비·radius·액센트를 정밀하게 | page #FAFAFB, 텍스트 #0D0E10(진짜 검정 근처), primary #5E6AD2(Linear 인디고), radius 8/6 |

확정되면 이 표는 선택된 사다리 하나로 대체된다.

## 3. Anti-slop 금지 목록 (AI 디폴트 지문 — 게이트 B 채점 항목)

1. **스케일 밖 치수** — §1 표에 없는 높이/아이콘/radius 금지
2. **같은 행 컨트롤 높이 혼용** — 실측으로만 잡힘, 게이트 A 항목
3. **콘텐츠 의존 높이의 나란한 카드** — §1-3 위반
4. **장식용 좌측 컬러 바** — 상태 의미가 있을 때만 허용(FAILED 상태 바 1곳)
5. **의미 없는 깜빡임** — pulse는 "지금 실행 중" 의미가 있는 RUNNING dot 1종만
6. **배지 중첩** — 한 셀/한 행에 배지 2개까지. 3중첩부터 소음
7. **근거 없는 파랑 남용** — primary는 액션·선택·링크 전용. 정보 강조는 weight·색 단계로
