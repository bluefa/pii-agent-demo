TargetSource 생성일과 최초 연동일

TargetSource 가 언제 만들어졌고 언제 처음 연동을 마쳤는지 기간으로 잘라 봅니다. 최초 연동일은 초기화로 단계가 되돌아가도 바뀌지 않습니다.

기준
기간
최초 연동
서비스 최초 연동 확정 상태
예시 데이터 · 리드타임은 API 가 보낸 초 단위 값을 일·시간으로만 표시
신규 API 초안 install-v1 · admin

기존 목록 API 는 기간 파라미터가 없어 전체를 받아 클라이언트에서 잘라야 합니다. 이 화면을 위해 기간·기준·최초 연동 여부·정렬을 받는 엔드포인트를 새로 둡니다. 행은 기존 TargetSourceResponse 의 부분집합에 lead_time_seconds 하나를 더한 것이고, 요약·통계 필드는 두지 않습니다.

GET /install/v1/admin/target-sources/integration-timeline

Query
  axis           CREATED | FIRST_INSTALLED   (기본 CREATED)
  from, to       date (YYYY-MM-DD, 포함 구간)
  installed      ALL | YES | NO   (기본 ALL)
  serviceCode    string
  confirmStatus  기존 enum 그대로
  page, size, sort   (sort=leadTimeSeconds,desc 등)

axis=FIRST_INSTALLED 이면 installed=NO 는 빈 결과.
축이 최초 연동일이면 미완료 행은 구간에 들어올 수 없기 때문.
200  PageTargetSourceIntegrationTimelineResponse
{
  "content": [{
    "target_source_id": 4130,
    "service_code": "SVC-PAY",
    "service_name": "결제 정산",
    "confirm_status": "CONFIRMED",
    "created_at": "2026-07-02T10:12:00+09:00",
    "pii_agent_first_installed_at": "2026-07-11T16:40:00+09:00",
    "lead_time_seconds": 800880
  }],
  "totalElements": 41, "totalPages": 3, "first": true, "last": false
}

lead_time_seconds 는 최초 연동 완료 행만, 아니면 null.
FE 표시: 9일 6시간 (1일 미만은 "6시간", 1시간 미만은 "1시간 미만")

CSV 는 같은 쿼리에 Accept: text/csv 로 내려받습니다. 클라이언트에서 페이지를 모아 만들지 않습니다. 중앙값·평균·기간 비교 같은 통계는 이 화면이 아니라 CSV 를 받은 쪽 도구의 몫입니다.
